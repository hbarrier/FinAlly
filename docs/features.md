# Features

Each feature maps to one page in the app. Click the feature name for full detail.

| Feature | Route | Summary |
|---|---|---|
| [Dashboard](features/dashboard.md) | `/dashboard` | Monthly overview: cashflow totals, upcoming recurring payments, spending by category |
| [Transactions](features/transactions.md) | `/transactions` | Full ledger of all income and expenses; filter, clear, and link to recurring items |
| [Import](features/import.md) | `/transactions` (wizard) | CSV bank export ingestion with merchant mapping and deduplication |
| [Recurring](features/recurring.md) | `/recurring` | Manage bills and income that repeat on a schedule; track amount changes over time |
| [Budgets](features/budgets.md) | `/budgets` | Set monthly spending limits per category and compare against actual spend |
| [Goals](features/goals.md) | `/goals` | Track savings targets with visual progress and optional deadlines |
| [Reimbursements](features/reimbursements.md) | `/reimbursements` | Mark expenses as reimbursable, record repayment, and manage time-versioned reimbursement rates |
| [Categories](features/categories.md) | `/categories` | Classify transactions into labelled expense and income buckets |
| [Merchants](features/merchants.md) | `/merchants` | Manage vendors, assign default categories, and merge duplicates |
